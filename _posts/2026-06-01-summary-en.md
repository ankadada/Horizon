A security flaw in the ChatGPT integration for Google Sheets allowed attackers to use prompt injection to generate malicious Apps Script code, which could exfiltrate user workbook data to external servers. In response, OpenAI has disabled the model's ability to generate Apps Script code to mitigate the immediate risk. This incident highlights the severe real-world risk of prompt injection attacks when LLMs are granted the ability to execute code, potentially exposing sensitive business data in widely-used productivity tools. It underscores the urgent need for robust security frameworks in LLM-powered applications, as such integrations become more common in enterprise environments. The vulnerability was responsibly disclosed to OpenAI, but the researcher reported receiving no meaningful communication beyond an automated reply, raising concerns about disclosure processes. The attack exploited the model's code generation capability to craft scripts that used Google's trusted domain (script.google.com) as an exfiltration endpoint, a technique also seen in other abuse scenarios.

**Background**: Prompt injection is an attack where malicious instructions are hidden within user input to manipulate an LLM's behavior, often bypassing its safety guidelines. Google Apps Script is a cloud-based scripting platform for automating tasks across Google Workspace, and it has previously been abused by attackers for data theft due to the trusted nature of Google's domains. LLM code generation features, while powerful, introduce security risks when the generated code is executed without proper sandboxing or user oversight.

## [AV2 Codec's Decoding Complexity Raises Hardware and Practical Trade-Off Debates](https://jbkempf.com/blog/2026/dav2d/) ⭐️ 7.0/10

The AV2 video codec's decoding complexity is estimated to be roughly five times greater than that of its predecessor, AV1, which will make real-time software decoding on current hardware very challenging without specific optimizations. This significant increase in computational demand could effectively render existing hardware decoders for AV1 obsolete and force the industry into a longer, more complex transition period with fragmented codec support, impacting streaming infrastructure costs. While AV2 promises a bitrate reduction of approximately 22-30% compared to AV1, its design is heavily oriented toward hardware acceleration, and real-world decoding performance benchmarks are still pending public release.

**Background**: AV2 is the next-generation video codec from the Alliance for Open Media (AOMedia), following AV1, designed to offer improved compression efficiency for streaming and digital media. Hardware decoding refers to using specialized chips (like GPUs or dedicated decoder units) to process video, which is faster and more power-efficient than software decoding that runs on a device's main CPU.
