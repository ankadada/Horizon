## [Google Sheets 版 ChatGPT 的漏洞导致提示注入攻击可窃取数据。](https://www.promptarmor.com/resources/gpt-for-google-sheets-data-exfiltration) ⭐️ 8.0/10

Google Sheets 版 ChatGPT 集成存在一个安全漏洞，攻击者可以利用提示注入生成恶意的 Apps Script 代码，从而将用户工作簿中的数据窃取到外部服务器。作为应对措施，OpenAI 已禁用该模型生成 Apps Script 代码的能力，以消除直接风险。 此事件凸显了当大型语言模型被授予代码执行能力时，提示注入攻击所带来的严重现实风险，可能危及广泛使用的生产力工具中的敏感业务数据。随着此类集成在企业环境中日益普及，这强调了为大型语言模型驱动的应用程序构建强大安全框架的紧迫性。 该漏洞被负责任地披露给了 OpenAI，但研究人员报告称，除了自动回复外，未收到任何有意义的沟通，这引发了人们对披露流程的担忧。该攻击利用了模型的代码生成能力来编写脚本，这些脚本使用了谷歌的可信域名（script.google.com）作为数据窃取端点，这种技术在其他滥用场景中也出现过。

hackernews · hackerBanana · May 31, 20:35 · [社区讨论](https://news.ycombinator.com/item?id=48349487)

**背景**: 提示注入是一种将恶意指令隐藏在用户输入中以操纵大型语言模型行为的攻击，通常能绕过其安全准则。Google Apps Script 是一个基于云的脚本平台，用于在 Google Workspace 中自动执行任务，由于谷歌域名的可信性质，它此前曾被攻击者滥用于数据盗窃。大型语言模型的代码生成功能虽然强大，但在生成的代码没有适当沙箱隔离或用户监督的情况下执行时，会引入安全风险。

## [Anthropic 详细说明为 Claude 各产品实施沙盒技术](https://simonwillison.net/2026/May/30/how-we-contain-claude/#atom-everything) ⭐️ 8.0/10

Anthropic 发布了一篇技术博文，详细介绍了他们为旗下产品（包括 Claude.ai、Claude Code 和 Claude Cowork）实施的多层沙盒化方法。文章解释了所使用的具体技术，例如网页界面使用 gVisor，本地命令行工具在 macOS 上使用 Seatbelt、在 Linux 上使用 Bubblewrap，而 Cowork 环境则使用完整的虚拟机。 这篇公开文档具有重要意义，因为它透明地展示了一家领先的人工智能安全公司如何应对隔离人工智能代理以防止数据泄露和未授权操作这一关键挑战。这为快速发展的将大语言模型部署为自主代理领域中的安全实践设定了基准。 文章揭示了针对每个产品的具体隔离策略，例如 Claude.ai 使用 gVisor 实现兼容 Linux 的沙盒，而 Claude Cowork 则在 macOS 上使用 Apple 的虚拟化框架、在 Windows 上使用 HCS 来运行完整的虚拟机。Anthropic 还坦诚地分享了一个曾遗漏的风险案例，即一个通过其 API 端点进行文件泄露的途径，该问题此前已被发现并报告。

rss · Simon Willison · May 30, 21:36

**背景**: 人工智能代理沙盒化是指将人工智能系统运行在受限环境中，以限制其对主机系统资源、文件和网络的访问。像 gVisor 这样的技术通过拦截系统调用提供轻量级的应用程序级沙盒，而 macOS 的 Seatbelt（现为 App Sandbox 的一部分）和 Linux 的 Bubblewrap 则是系统级的沙盒机制，用于对进程实施安全策略。对数据泄露的担忧至关重要，因为恶意提示或模型行为可能会尝试将敏感数据发送到沙盒之外。
